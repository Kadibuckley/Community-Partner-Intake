Features Enabled with Sheet Integration:

  • Automatic pushing of intake form responses to Google Sheet rows.
  • Automatic timestamping in dedicated Date Submitted column.
  • Bidirectional pulling of all partner submissions back into the directory.
  • CSV report downloads for offline reporting.

2-Minute Google Sheet Setup

  1. Create or open your target Google Sheet.
  2. In the top menu, click Extensions > Apps Script.
  3. Copy and paste all contents from Code.gs into the editor.
  4. Click Deploy > New deployment.
  5. Select type: Web app.
  6. Set "Execute as": Me.
  7. Set "Who has access": Anyone.
  8. Click Deploy, grant permissions, and paste the Web App URL in the input field!
